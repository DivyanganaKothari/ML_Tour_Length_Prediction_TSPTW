📌 Thesis Project: Predicting Optimal Tour Length for the Traveling Salesman Problem with Time Windows (TSP-TW) using Machine Learning
This project leverages Machine Learning to predict the optimal tour length for the Traveling Salesman Problem with Time Windows (TSP-TW), improving real-time routing efficiency and logistics optimization for businesses dealing with dynamic delivery schedules. The approach combines Predictive Modeling, Time-Series Forecasting, and Data Engineering to address one of the most challenging combinatorial optimization problems.

Key Highlights
Applied Predictive Modeling & Time-Series Forecasting to analyze historical tour lengths and predict optimal routes based on time windows.

Developed and optimized a variety of ML models (including Neural Networks, Random Forest, and SVR) for accurate and efficient tour length estimation.

Conducted feature engineering and statistical analysis to identify and understand the critical factors influencing tour efficiency.

Designed and implemented scalable data pipelines for managing and processing large datasets using Python, Pandas, and NumPy.

Created interactive visualizations to present insights and enable data-driven decision-making.

Technologies Used
🔧 Programming Languages & Libraries: Python, Scikit-learn, TensorFlow
🔧 Data Processing & Analysis: Pandas, NumPy
🔧 Visualization: Matplotlib, Seaborn
🔧 Modeling Techniques: Machine Learning, Time-Series Forecasting, Statistical Analysis

This research makes a significant contribution to AI-driven logistics optimization, helping to reduce computational complexity while maintaining high accuracy and enhancing the performance of real-time routing systems.
